# Code Examples and Projects

This directory contains code examples and projects demonstrating various programming concepts.

## Object-Oriented Programming Examples

### Python Example (`python/student.py`)
A Student Management System demonstrating:
- **Classes and Objects**: Person, Student, and GraduateStudent classes
- **Inheritance**: Student inherits from Person, GraduateStudent inherits from Student
- **Encapsulation**: Protected attributes with getter methods
- **Polymorphism**: Method overriding with `display_info()`

**To run:**
```bash
cd oop-examples/python
python student.py
```

### Java Example (`java/Student.java`)
A Student Management System demonstrating the same OOP concepts in Java:
- **Classes and Objects**: Person, Student, and GraduateStudent classes
- **Inheritance**: Using extends keyword
- **Encapsulation**: Private and protected access modifiers
- **Polymorphism**: Method overriding with @Override annotation

**To run:**
```bash
cd oop-examples/java
javac StudentDemo.java
java StudentDemo
```

## Learning Resources

These examples are designed to help understand fundamental Object-Oriented Programming concepts covered in CIS361 coursework.

### Key OOP Concepts Demonstrated:
1. **Encapsulation**: Data hiding using access modifiers
2. **Inheritance**: Code reuse through parent-child class relationships
3. **Polymorphism**: Method overriding for specialized behavior
4. **Abstraction**: Simplifying complex systems through classes
